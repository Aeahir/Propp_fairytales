# Propp_fairytales
Tool for rewriting news or any other texts into fairytales with plots based on Propp's plot features and types of characters.

Локальное десктопное приложение на Python для адаптации взрослых мировых новостей в формат глубоких, психологически безопасных русских волшебных сказок на основе морфологии волшебной сказки Владимира Проппа [1].

Проект разработан как инструмент для исследований в области детской психологии, медиаобразования и нарративного анализа. Он позволяет изучать влияние художественной метафоризации новостей на снижение детской тревожности и развитие системного мышления у детей младшего школьного возраста.

💡 Основные возможности
Глубокая метафоризация: Программа не просто пересказывает новость простыми словами, а извлекает её сущностный конфликт и переводит его в независимый, глубокий сюжет в сеттинге русского фольклора (с использованием сказочного анимализма, купцов, воевод и ратников).

5 фундаментальных фаз Проппа: Сюжет каждой сказки выстраивается строго по адаптированной научной схеме В. Я. Проппа [1]:

Правило / Статус-кво

Вызов / Недостача (метафора проблемы)

Испытание / Поиск

Сеча / Преодоление

Преображение / Урок

Пропповский анализ событий: Встроенный модуль автоматически сопоставляет сказочные аллегории и фазы сюжета с реальными фактами из новости, формируя научно-методический разбор [1].

Детский словарик архаизмов: Программа автоматически извлекает устаревшие русские слова, использованные в сказке, и объясняет их простым языком.

Универсальный API-клиент: Поддержка любого OpenAI-совместимого эндпоинта (OpenAI, DeepSeek, Groq, OpenRouter или локальный vLLM) [4].

Потоковый вывод (Streaming): Текст генерируется в реальном времени символ за символом, обеспечивая отзывчивость интерфейса.

Локальная библиотека: Система сохранения получившихся сказок в JSON-архив с возможностью быстрого поиска и восстановления сессий.

🛠 Установка и требования
Для работы приложения необходим установленный интерпретатор Python версии 3.10 или выше.

Клонируйте репозиторий:

code
Bash
git clone https://github.com/Aearhir/Tales_from_news.git
cd Tales_from_news
Установите зависимости:

code
Bash
pip install -r requirements.txt
(Содержимое файла requirements.txt: customtkinter, openai)

Запуск приложения:

code
Bash
python app_propp_fairytales.py
🚀 Настройка и запуск генерации
В боковой панели укажите параметры вашего API-провайдера:

API Base URL: Адрес вашего эндпоинта (например, https://api.openai.com/v1 для OpenAI или https://api.deepseek.com для DeepSeek) [4].

API Key: Ваш ключ доступа.

Модель: Название модели (например, gpt-4o-mini или deepseek-chat).

Вставьте исходную взрослую новость в поле справа.

Нажмите кнопку «Переложить новость на сказочный мотив» и наблюдайте за генерацией во вкладках.

Чтобы сохранить результат в локальный архив, укажите название в поле сохранения и нажмите кнопку «Сохранить в Библиотеку».
